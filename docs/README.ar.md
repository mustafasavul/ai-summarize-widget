# AI Summarize Widget ✨

ودجة صغيرة وآمنة للـ CSS تتيح للزوار إرسال مقالاتك إلى **ChatGPT أو Claude أو Gemini أو Perplexity** بنقرة واحدة.

📦 **NPM:** https://www.npmjs.com/package/ai-summarize-widget

---

## ⚡ التثبيت في 5 دقائق

### الخطوة 1 — أضف السكريبت

الصق هذا السطر قبل وسم `</body>` في صفحتك مباشرةً:

```html
<script src="https://unpkg.com/ai-summarize-widget/dist/ai-summarize-widget.min.js"></script>
```

> **تستخدم NPM؟**
> ```bash
> npm install ai-summarize-widget
> ```
> ```js
> import AISummarizeWidget from 'ai-summarize-widget';
> ```

---

### الخطوة 2 — شغّل الودجة

أضف هذا مباشرةً أسفل السكريبت. هذا كل شيء!

```html
<script>
  new AISummarizeWidget({
    type: 'fixed',  // يُظهر زر ✨ عائم في أسفل يمين الصفحة
    lang: 'ar'
  });
</script>
```

افتح صفحتك — سيظهر **زر ✨** في الزاوية اليمنى السفلى. انقر عليه، اختر مساعد ذكاء اصطناعي، يُنسخ المحتوى تلقائياً وتُعاد توجيهك فوراً.

## 🔧 نمطا الاستخدام

### النمط 1: زر عائم + نافذة (`type: 'fixed'`)

زر ثابت في زاوية الشاشة. النقر عليه يفتح نافذة حوار في المنتصف. **مثالي للمدونات ومواقع الأخبار.**

```html
<script>
  new AISummarizeWidget({
    type: 'fixed',
    theme: 'auto',           // 'auto' | 'dark' | 'light'
    buttonColor: '#4f46e5',  // أي لون HEX
    lang: 'ar'
  });
</script>
```

### النمط 2: زر مضمّن + نافذة منبثقة (`type: 'inline'`)

يحقن الزر داخل عنصر موجود في صفحتك (مثل أزرار المشاركة).

```html
<!-- أزرار المشاركة الحالية -->
<div class="share-area">
  <button>مشاركة على X</button>
  <!-- ✨ سيُحقن الزر هنا -->
</div>

<script>
  new AISummarizeWidget({
    type: 'inline',
    target: '.share-area',  // المحدد CSS للعنصر المستهدف
    theme: 'dark',
    buttonColor: '#10b981'
  });
</script>
```

## 🌗 الثيم (`theme`)

| القيمة | السلوك |
|---|---|
| `'auto'` *(افتراضي)* | يتبع إعداد الوضع الداكن/الفاتح في نظام التشغيل، ويتحدث فورياً |
| `'dark'` | وضع داكن دائماً |
| `'light'` | وضع فاتح دائماً |

---

## ⚙️ جميع الخيارات

| الخيار | النوع | الافتراضي | الوصف |
|---|---|---|---|
| `type` | `String` | `'fixed'` | `'fixed'` (زر عائم + نافذة) أو `'inline'` (حقن داخل حاوية) |
| `theme` | `String` | `'auto'` | الثيم: `'auto'`، `'dark'`، `'light'` |
| `target` | `String` | `null` | **مطلوب لـ `'inline'`**. محدد CSS للعنصر المُراد حقن الزر فيه |
| `buttonColor` | `String` | `'#4f46e5'` | لون الزر (أي قيمة HEX أو RGB) |
| `lang` | `String` | *تلقائي* | رمز اللغة: `'ar'`، `'en'`، `'fr'`… يقرأ لغة المتصفح إن لم يُحدَّد |
| `redirectDelay` | `Number` | `1200` | المدة (بالميلي ثانية) قبل التوجيه إلى مساعد الذكاء الاصطناعي |
